Position (from the origin, cm)

Coordinates: x right, y up, z toward the screen. Path length is measured by I/Q phase tracking (as LLAP does), and position is the relative change from the origin. Hold your hand still for 1 s to reset the origin. With the laptop alone, the two mics sit side by side above the screen, so height (y) is not observable(third singular value ≈ 0). So height is held fixed and only the x·z plane is solved. 📱 Standing phone A at 17.0 kHz and B at 18.75 kHz (iPhones can’t play above 20 kHz) beside the screen adds paths, so height can be solved too. Phone clock error is removed using the phase of the direct phone→mic path (PLL). Measured (webcam ground truth; eight sittings, each held out as the test after training on the others; hand within 45 cm of the webcam; 250 ms movement; balanced size; tracker v2): x 3.8, y 2.5, z 4.3 cm (correlation 0.73/0.57/0.70).
